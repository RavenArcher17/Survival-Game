# Skill trees

Every path tree has the same shape: a 10-point trunk, then three branches of 30 points each, so 100 points max out a whole tree. Stat nodes have ranks at 1 point each; abilities cost several points. All names and numbers are first drafts.

**Rules for every tree**

- Points come from path XP, earned by using that path's abilities.
- 150 points total across two paths, with no path above 100.
- Each tree has a free root passive. It's active only when that path is your main path; on a subclass it still shows, detached from the trunk.
- Each capstone costs 10 points and ends its branch.
- Owning two paths unlocks two automatic combos, at 25/25 and 50/50 points. Combos cost no points.
