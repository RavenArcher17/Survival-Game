# Design docs (copies)

Raven writes the game's design in Claude Docs; these are markdown exports of them from **2026-11-08**, so a session
without access to Raven's account can read them. Raven keeps editing the live docs, so these go stale: ask for a fresh
export before a big piece of work, and replace the files whole (don't edit them here).

| File | What |
|---|---|
| `build-plan.md` | scope and order: First playable, Full release, Dream list, the gates, and "Where it stands" (what's built) |
| `design-doc.md` | the overview: pillars, paths, combat, taming, survival, building, PvP and the rest |
| `skill-trees.md` | each path's tree |
| `combos.md` | the automatic combos for every pair of paths (at 25/25 and 50/50 points) |
| `crafting.md` | tech levels, quality and sockets, upgrades |
| `life-skills.md` | life skills and perks |
| `bosses.md` | the bosses |
| `creatures.md` | the creature roster |
| `map.md` | the first playable map's areas (its diagram, and the build plan's roadmap picture, didn't export) |
| `server-settings.md` | server settings and presets |
| `building.md` | building |
| `starting-numbers.md` | the first-draft numbers (the game's live ones are in `Data/tuning.json`) |

**Scope is the build plan's First playable tier, fire and frost only.** Everything in these is a first draft; where tabs
disagree, `Docs/DESIGN_REVIEW.md` has the open questions.
