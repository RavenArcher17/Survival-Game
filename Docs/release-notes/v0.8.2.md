**Download: [Wildreach-Setup.exe](https://github.com/RavenArcher17/Survival-Game/releases/latest/download/Wildreach-Setup.exe)** (Windows 10/11, 64-bit: a small program that downloads the game and installs it)

Already have Wildreach? Start it from its shortcut: it updates itself to 0.8.2 and your saves are kept. Or click **Update now** on the main menu: Wildreach closes, installs the update and starts again by itself. This update downloads most of the game again (about 2.4 GB) because the game's files are now cut into smaller pieces; updates after it fetch only what changed. New here? Double-click the installer: it installs to your user folder, no admin needed, adds Desktop and Start Menu shortcuts and starts the game. To remove it, use "Uninstall Wildreach" in the Start Menu.

Windows may say "Windows protected your PC" because the installer isn't code-signed: click **More info**, then **Run anyway**.

Everyone in a game needs the same version, so make sure your friends update too.

## New in 0.8.2

- **Quitting no longer crashes.** Closing the game, from the main menu or from a world, used to end in a crash after everything was saved; it now closes cleanly.
- **A smaller, faster game.** Players get the release build of the game instead of the testers' build, without the debugging files, and only the art the game uses goes in, at 2K. The game is about 3.1 GB on disk, down from 4.4 GB.

## Playing with friends

1. Start Wildreach, type a name, and pick your look and your path.
2. One person clicks **Host a game** and chooses a world. Everyone else types the host's IP and clicks **Join**.
   - Same Wi-Fi: the host's local IP (`ipconfig`, "IPv4 Address").
   - Over the internet: the host forwards UDP port 7777 on their router to their PC and shares their public IP.
3. Every key can be changed in Esc > Controls, and F1 shows them in game.
